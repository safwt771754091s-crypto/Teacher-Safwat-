# إدخال الكتب المدرسية كاملةً — معلمي الذكي اليمني

هذه الوثيقة تشرح كيف يُدخل **الكتاب المدرسي كاملًا** (نصّه الحرفي صفحةً صفحة) إلى المنصة،
حتى يصبح متاحًا للشرح والاستماع والتحميل. لا يخترع النظام نصًّا: كل صفحة تُخزَّن كما استُخرجت
من الكتاب، مع رقم صفحتها، وتُعلَّم للمراجعة البشرية قبل الاعتماد.

## الطريق الأول: لوحة المعلم/المشرف (كتاب واحد)

1. `POST /api/v1/textbooks` لإنشاء الكتاب (يُربط بالمادة والصف).
2. `POST /api/v1/textbooks/{id}/upload-pdf` (ملف `file` بصيغة PDF، حتى 50MB) — يستخرج النص
   صفحةً صفحة إلى `textbook_pages`، ويسجّل عدد الصفحات، ويضع الكتاب في حالة `review`.
   - للصفحات الممسوحة ضوئيًا (بلا طبقة نص) يشغّل OCR عربيًا تلقائيًا عند توفّره.
3. `GET /api/v1/textbooks/{id}/pages` لمراجعة النص المستخرج لكل صفحة.
4. `PATCH /api/v1/pages/{page}` لتصحيح أي صفحة لم تُقرأ بوضوح (`extracted_text` + `status=reviewed`).
5. `POST /api/v1/textbooks/{id}/draft-lessons` لإنشاء الدروس المسودة من الصفحات.
6. `POST /api/v1/textbooks/{id}/publish` لنشر الكتاب بعد الاعتماد.

بعد الرفع، يضمّن زر **«تحميل الكتاب كامل»** نصّ الصفحات الفعلي في ملف PDF/HTML.

## الطريق الثاني: استيراد جماعي (كل المنهج)

للرفع بالجملة من قائمة روابط كتب رسمية، جهّز ملف JSON (manifest) بالشكل:

```json
[
  {"title": "الرياضيات - الصف الأول", "url": "https://…/math-g1.pdf",
   "grade_level": 1, "subject": "الرياضيات", "term": "first",
   "authority": "common", "branch": "general"}
]
```

ثم شغّل:

```bash
php artisan textbooks:import manifest.json            # الكل
php artisan textbooks:import manifest.json --grade=1  # صف واحد
php artisan textbooks:import manifest.json --no-ocr   # طبقة النص فقط (أسرع)
php artisan textbooks:import manifest.json --draft-lessons
```

الخيارات: `--limit` / `--offset` / `--count` (تقسيم العمل)، `--authority` / `--tag-authority`،
`--keep-files`. الأمر يُحمّل كل كتاب، يستخرجه صفحةً صفحة، ويربطه بالمادة/الصف، ولا يخترع شيئًا.

## أين نضع ملفات الكتب؟

- الكتب المحلية: ضعها في `backend/storage/app/textbooks/` أو استخدم لوحة المعلم مباشرةً.
- روابط عامة: استخدم manifest مع `textbooks:import`.

## ملاحظة عن المنهج الحالي

هيكل المنهج الحالي (12 صفًا، 118 مادة، ~1200 درس) يحمل **أسماء الوحدات والدروس** فقط؛
الشرح/الملخص/التمارين مُولَّدة ومُسنَدة إلى صفحات الكتاب. النصّ الحرفي الكامل يظهر بعد رفع
ملفات PDF/صور الكتب الرسمية عبر الخطوات أعلاه. إذا لم تكن الصورة واضحة يبقى مصدر الحقيقة
هو الصورة الأصلية، ويطلب النظام صورة أوضح بدل التخمين.
